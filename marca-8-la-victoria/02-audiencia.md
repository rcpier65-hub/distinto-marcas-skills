# 02 · AUDIENCIA — La Victoria

> Personas + insights + objeciones para conectar.

---

## 🎯 Audiencia core (B2B + B2B-pequeño)

### Geografía
- **Lima Metropolitana** (foco)
- **Provincias** (envíos vía agencia)

### Segmentos
- **Almacenes / centros de distribución** que necesitan tarimas para storage
- **Exportadoras** que necesitan parihuelas (pallets) para empacar mercadería
- **Constructoras / contratistas pequeño-mediano** que usan madera dimensionada
- **Carpinteros independientes** que compran tablones / repisas
- **Mueblerías / talleres pequeños** que necesitan madera para fabricación
- **Dueños de negocio** (bodegas, restaurantes) que requieren repisas a medida

---

## 👤 Persona #1 — "Roberto, jefe de almacén / logística"

| Campo | Valor |
|---|---|
| **Edad** | 38-50 |
| **Cargo** | Jefe de almacén / logística en empresa mediana |
| **Empresa** | Distribuidora / exportadora / industria |
| **Plataformas** | WhatsApp + LinkedIn (poco) + Facebook |

**Día típico**:
- Coordina cargas de mercadería (necesita tarimas listas)
- Negocia con proveedores de empaque/madera
- Audita stock de tarimas / parihuelas

**Pain points**:
- Proveedor no entrega a tiempo → para línea de despacho
- Calidad inconsistente (tarima rota = mercadería dañada)
- Precio sube sin aviso

**Por qué La Victoria le habla**:
- Fabricación propia = control de calidad
- Plazos cumplidos
- Atención directa por WhatsApp (no call center)
- Precios estables

**Objeciones**:
- "¿Manejan stock o todo es bajo pedido?"
- "¿Cuál es el plazo de entrega típico?"
- "¿Manejan crédito 30 días?"

**Cómo neutralizar**:
- Mostrar producción / almacén (transparencia)
- Casos de cliente regulares
- Política de plazos clara

## 👤 Persona #2 — "Carlos, contratista / constructor pequeño-mediano"

| Campo | Valor |
|---|---|
| **Edad** | 35-55 |
| **Cargo** | Contratista de obras |
| **Plataformas** | WhatsApp + Facebook |

**Pain points**:
- Necesita madera dimensionada lista (no quiere cortar él)
- Repisas / encofrado para obra
- Cumplir plazos de cliente

**Por qué La Victoria le habla**:
- Madera lista para usar
- Variedad de medidas
- Despacho a obra
- Atención directa

**Objeciones**:
- "¿Cortan a medida si pido?"
- "¿Despachan a [obra en distrito]?"
- "¿Aceptan pago contraentrega?"

## 👤 Persona #3 — "Andrea, dueña de bodega/restaurante necesita repisas"

| Campo | Valor |
|---|---|
| **Edad** | 30-50 |
| **Cargo** | Dueña pyme / negocio |
| **Plataformas** | Instagram + WhatsApp |

**Contexto**:
- Acaba de abrir o renovar negocio
- Necesita repisas, mesones, mobiliario madera básico
- Busca calidad sin pagar mueblería boutique

**Por qué La Victoria le habla**:
- Madera para repisas (línea documentada)
- Atención directa y rápida
- Precio competitivo
- Cercanía (responde por DM/WhatsApp)

**Objeciones**:
- "¿Tienen modelos prefabricados o todo es a medida?"
- "¿Vienen a instalar?"
- "¿Cuánto cuesta el m2 / pieza?"

## 👤 Persona #4 — "Marco, carpintero independiente"

| Campo | Valor |
|---|---|
| **Edad** | 30-55 |
| **Cargo** | Carpintero / mueblista solo o con equipo pequeño |
| **Plataformas** | Facebook + WhatsApp + visita presencial |

**Pain points**:
- Necesita tablones / madera dimensionada lista
- Precio mayorista (compra en cantidad)
- Cumplir su entrega a su propio cliente

**Por qué La Victoria le habla**:
- Mayorista friendly (sin pedir mucho papeleo)
- Variedad de maderas/medidas
- Cercanía + ubicación accesible
