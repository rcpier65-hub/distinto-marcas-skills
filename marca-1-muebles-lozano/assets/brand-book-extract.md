## 🏢 Identidad oficial

### Naming
- **Razón social**: Muebles Lozano SAC
- **Nombre comercial**: Muebles Lozano
- **Wordmark del logo**: "MUEBLES LOZANO"
- **Tagline / propuesta**: empresa de muebles a medida — moderno, dinámico, eficiente

### Concepto del isotipo (página 5)
> "El isotipo de la marca está compuesto por una combinación de muebles
> (un ropero y un escritorio de forma sintetizada).
> Se realizó un diseño imagotipo, con una tipografía que transmite
> seriedad, formalidad y un color que transmite fuerza y confianza."

**Visualmente**:
- Silueta de **casa con techo a dos aguas** (representa hogar)
- Letras **"M" y "L"** dentro de la silueta de la casa
- M en **negro** | L en **amarillo**
- Wordmark "MUEBLES LOZANO" debajo, en sans serif con tracking amplio

### Tipo de marca
**IMAGOTIPO** — el símbolo (isotipo) y la tipografía pueden funcionar separados.

### Significado de cada color (página 6)
- **Amarillo**: vibrante, energético, atrae interés visual
- **Negro**: elegancia, sofisticación, productos clásicos / lujo / alta calidad
- **Blanco**: simplicidad, prácticidad, armonía

### Escala de grises (página 7)
El logo en grises **usa una sola tinta (negro)** — para impresión limitada a un color (negro). Útil para prensa B/N, fax, impresión económica.

## 🔤 Tipografía oficial (página 8)

### PRIMARIA — Opificio Neue
- Para títulos y headlines principales
- ⚠️ **CRÍTICO**: NO tiene versión bold
- Para énfasis se usa **borde** (no peso):
  - Letras grandes → borde 1.0 px
  - Letras medianas → borde 0.5 px
  - Letras pequeñas → borde 0.25 px

### SECUNDARIA — Myriad Pro
- Para subtítulos, datos de empresa, números, correos, dirección

### Substitutos OSS para producción Python
- Opificio Neue → **Bebas Neue** o **Oswald Light**
- Myriad Pro → **Inter** o **Open Sans**

## ❌ Aplicaciones PROHIBIDAS (página 11 — B.02)

> 6 violaciones que el manual marca con ❌:

1. **Aplicación incorrecta de color** (usar colores fuera de paleta)
2. **Porcentajes de color** (no usar opacidades del logo — siempre 100%)
3. **Deformación** (no estirar/comprimir)
4. **Espacio incorrecto** (respetar zona seguridad 0.5x)
5. **Ocultación** (no cortar parte del logo)
6. **Deformación tipográfica** (no modificar el wordmark)

## 🎯 Lineamientos para producción de contenido digital

### Cuándo usar cada versión del logo

| Pieza | Versión recomendada |
|---|---|
| Post IG 1080×1080 fondo blanco | Logo positivo color |
| Post IG fondo negro/oscuro | Logo negativo (blanco + amarillo) |
| Story IG fondo amarillo | Logo positivo color (M negra + L blanca) |
| Watermark / esquina | Solo isotipo (casa con ML) |
| Carrusel última slide | Logo completo positivo |

### Heurísticas de composición

1. **El amarillo es protagonista cuando se usa** — bloque sólido, no degradado
2. **El negro sí puede ser bastante puro** (`#0C0C12` ≈ `#000000`)
3. **Espacio negativo respetado** — el logo necesita aire (mín 0.5x)
4. **No combinar el amarillo con otros tonos cálidos** (rojo, naranja) — solo con negro y blanco
5. **No usar bold en Opificio Neue** — usar borde
6. **Seriedad + formalidad** = la voz visual debe transmitir oficio (no diversión informal)
