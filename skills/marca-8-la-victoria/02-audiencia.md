## 🎯 Audiencia core (B2B industrial)

### Geografía
- **Lima Metropolitana** — foco principal (bodega Villa El Salvador)
- **Provincias** — vía agencia de transporte (cuando aplica grandes volúmenes)
- **Conos / parques industriales** — Villa El Salvador, Lurín, Ate, Santa Anita, Chorrillos, Callao

### Segmentos confirmados (del brochure La Victoria)

#### 1️⃣ Industria mueblera (B2B grande/mediano)
Talleres y fábricas que producen muebles serie / línea blanca / mobiliario hotel/hospital.

#### 2️⃣ Fabricantes de muebles (PYME / mediano)
Mueblerías independientes, talleres de Villa El Salvador, San Juan de Lurigancho.

#### 3️⃣ Estructuras de madera (constructoras + contratistas)
Empresas que usan madera para encofrados, andamios, estructuras temporales.

#### 4️⃣ Carpintería + proyectos personalizados
Carpinteros independientes, proyectos arquitectónicos custom.

#### 5️⃣ Industria de embalaje y pallets
- Exportadoras (palta, arándano, espárrago, mango)
- Almacenes / centros de distribución
- Empresas con flujo logístico continuo
- Importadores que necesitan parihuelas

### Cliente DEYJIM (marca hermana — armazones)
- **Mueblerías de cama** que compran armazones para revender
- **Importadores de colchones** que necesitan box-tarima
- **Tiendas online de dormitorio**
- **Hoteles / hospedajes** renovando habitaciones (B2B mediano)
- **Consumidor final B2C** (raro pero existe — vía WhatsApp)

## 👤 Persona #1 — "Roberto, jefe de planta de mueblería mediana"

| Campo | Valor |
|---|---|
| **Edad** | 40-55 |
| **Cargo** | Jefe de producción / dueño de mueblería con 5-30 trabajadores |
| **Plataformas** | WhatsApp + Facebook + cotizaciones por mail |

**Día típico**:
- Coordina pedidos de muebles (departamentos, hoteles, oficinas)
- Calcula consumo de madera según pedido
- Negocia con 2-3 proveedores de pino radiata

**Pain points**:
- Pino que no llega a tiempo → para línea de producción
- Madera con humedad alta → muebles se deforman → reclamo cliente final
- Variabilidad de medidas → más mermas
- Subida sorpresiva de precio madera

**Por qué La Victoria le habla**:
- **Importación directa** = sin intermediarios = más estable en precio
- **Secado en cámara 15% humedad** = sin sorpresas en taller
- **Stock continuo + abastecimiento** = no para producción
- **Catálogo medidas estandarizadas** (20x45 hasta 37x245x3200 mm)
- **Atención personalizada** = trato directo, no call center

**Objeciones**:
- "¿Manejan crédito 30 días?"
- "¿Cuál es el tiempo de entrega de [medida específica]?"
- "¿Tienen factura electrónica?"
- "¿El precio incluye despacho a mi taller?"

**Cómo neutralizar**:
- Mostrar bodega Villa El Salvador (transparencia stock)
- Casos de cliente regulares (testimonios)
- Política de plazos clara
- Catálogo con medidas exactas (ya disponible)

## 👤 Persona #2 — "Carlos, fabricante de pallets para exportadora"

| Campo | Valor |
|---|---|
| **Edad** | 35-55 |
| **Cargo** | Dueño de fábrica de tarimas / pallets |
| **Cliente final** | Agroexportadoras de palta, arándano, espárrago |
| **Plataformas** | WhatsApp + Facebook + visita presencial |

**Pain points críticos**:
- Sus exportadoras requieren **tarimas con medidas exactas** (norma internacional)
- Subida del precio del pino le come margen
- Necesita stock permanente para responder a campañas agrícolas

**Por qué La Victoria le habla**:
- **TACO 90x90x3200 / 1600** — medidas estándar para parihuelas
- **TABLA 16x90x3960 / 16x90x2440 / 16x70 / 16x45** — todo el surtido para fabricar tarimas
- **"Precisión dimensional + Alta resistencia estructural + Stock permanente + Precios competitivos"** (claim documentado en brochure)
- **Importación directa** = mejor precio = más margen

**Objeciones**:
- "¿Manejan volumen alto continuo?"
- "¿Pueden cumplir contrato anual?"
- "¿La madera está tratada para exportación (HT)?"
- "¿Crédito? ¿Factura?"

| Campo | Valor |
|---|---|

| **Cargo** | Carpintero solo / con equipo pequeño |
| **Volumen** | Compra mediana (no megacliente, pero recurrente) |
| **Plataformas** | Facebook + WhatsApp + visita personal |

**Pain points**:

- Atención WhatsApp directa
- Ubicación accesible (Villa El Salvador, parque industrial)

## 👤 Persona #4 — "Andrea, jefe compras agroexportadora"

| Campo | Valor |
|---|---|
| **Edad** | 30-50 |
| **Cargo** | Jefe de logística / compras en exportadora mediana-grande |
| **Volumen** | Alto recurrente (campañas agrícolas) |
| **Plataformas** | Email + LinkedIn + WhatsApp empresarial |

**Pain points**:
- Necesita certificación FSC / madera tratada para exportación
- Volumen alto que no puede fallar (campaña agrícola = días contados)
- Crédito empresarial 30-60 días

**Por qué La Victoria le habla**:
- Importación directa = volúmenes garantizados
- Bosques reforestados = compatible con certificaciones cliente final
- 15 años respaldo = confiable para B2B

**Objeciones**:
- "¿Tienen FSC?"
- "¿Manejan tratamiento HT (heat treated) para exportación?"
- "¿Qué crédito B2B manejan?"

## 👤 Persona #5 — "Yamilet, mueblería de camas que compra armazones DEYJIM"

| Campo | Valor |
|---|---|
| **Edad** | 28-50 |
| **Cargo** | Dueña de mueblería pequeña-mediana especializada en dormitorio |
| **Plataformas** | Instagram + Facebook + WhatsApp |

**Contexto**:
- Compra **box tarimas / armazones DEYJIM** para revender (con o sin tapizado)
- Necesita armazones listos (1.5p, 2p, Queen, King)
- Algunos modelos con cajones para optimizar espacio

**Por qué DEYJIM le habla**:
- Pino radiata humedad <12% (no se mueve)
- Tratamiento térmico + secado horno
- Certificación FSC
- Nordex 2.5mm (firme)
- Precios documentados (ver `03-oferta-presencia.md`):
  - 1.5p / 2p solo armazón: S/92
  - Queen 2 piezas: S/165
  - King 2 piezas: S/185
  - Con cajones (1.5p o 2p): S/165

**Objeciones**:
- "¿Manejan stock o todo es bajo pedido?"
- "¿Hacen descuento por volumen?"
- "¿Despachan a mi tienda?"
