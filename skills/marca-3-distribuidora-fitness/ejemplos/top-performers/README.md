# Top Performers — Distribuidora Fitness Marketing

> Carpeta para guardar las **5-10 piezas reales** que mejor performaron.
> Each pieza tiene su propio archivo `.md` con: link a la pieza original + métricas + análisis.

---

## 📁 Estructura recomendada

```
top-performers/
├── 2026-04-reel-cumple-mama.md
├── 2026-03-carrusel-testimonio-juan.md
├── 2026-02-reel-detras-camaras.md
└── ...
```

---

## 📋 Plantilla para cada archivo

```markdown
# [Tipo] · [Tema corto] — [YYYY-MM-DD]

**Plataforma**: [IG Reels / TikTok / FB / etc.]
**Link a la pieza**: [URL Drive o IG]
**Pillar**: [de `04-contenido.md`]

## Métricas (al día de hoy)
- Views: [#]
- Likes: [#]
- Comments: [#]
- Shares: [#]
- Saves: [#]
- Engagement rate: [%]

## Por qué funcionó
[2-3 razones documentadas]

## Lo que aprendimos
[Insight aplicable a futuras piezas]

## Lo NO replicar (si aplica)
[Algo que funcionó pero no debería repetirse — ej. polémica casual]
```

---

## 🔄 Proceso mensual

Cada día 1:
1. Identificar las 1-3 piezas top del mes anterior (en métricas reales)
2. Crear archivo con plantilla de arriba
3. Si la carpeta ya tiene 10+ piezas, mover las más viejas a `top-performers/archivo/`
4. Mantener máximo 10 vivos para no saturar contexto cuando Claude consulta
