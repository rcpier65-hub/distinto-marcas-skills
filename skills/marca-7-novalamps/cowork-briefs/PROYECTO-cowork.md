## 📋 Setup paso a paso para este proyecto en Cowork

1. **Crear proyecto Cowork** con nombre exacto: `Distinto — NovaLamps`
2. **Conectar Drive**: `team@agenciadistinto.com`
3. **Filtrar acceso**: solo a `Mi unidad / 1. GESTIÓN / CUENTAS / 7. NovaLamps /`
   (NO darle acceso a otros clientes — protege confidencialidad)
4. **Pegar el prompt** del bloque arriba en "Instructions" / "System prompt"
5. **Test inicial**: preguntar
   > "Describime la voz de marca de NovaLamps en 3 frases citando el archivo donde está documentado."
   Si responde algo como *"Autoritativa con calidez, aspiracional para diseño, técnica accesible — según `00 - SKILL/01-marca.md`"*, el setup está correcto ✅
