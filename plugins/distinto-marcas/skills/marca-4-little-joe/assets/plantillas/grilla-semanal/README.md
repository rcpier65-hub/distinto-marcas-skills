# Plantilla base · Grilla semanal Little Joe

Plantilla vertical 4:5 para enviar al cliente al inicio de semana.

- Medida: 1200 x 1500 px
- Salida principal: `plantilla-grilla-semanal-little-joe.png`
- Generador editable: `generar_grilla_little_joe.py`
- Datos editables: `grilla-semanal-ejemplo.json`

## Criterios de marca usados

- Logo oficial blanco del kit de marca.
- Tipografia del kit: Big Shoulders Display.
- Fondo azul cielo tomado de las portadas destacadas de Little Joe.
- Bloques tipo planner con color de producto: azul, fucsia, amarillo, verde menta y crema.
- Recursos visuales de producto desde el banco de imagenes del cliente.
- Tono limpio, cute/playful y calido, sin exceso de texto.

## Uso rapido

Editar `grilla-semanal-ejemplo.json` y ejecutar:

```bash
python3 generar_grilla_little_joe.py
```

La plantilla ordena los contenidos por fecha y oculta dias sin contenido.
